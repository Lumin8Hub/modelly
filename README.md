# Modelly

One-page marketing site for Modelly, a boutique FP&A advisory and Excel-modelling practice.

## Stack

- Vite
- React
- Tailwind CSS
- Framer Motion
- lucide-react

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Deployment

GitHub Actions deploys the static Vite build to GitHub Pages on pushes to `main` using `.github/workflows/deploy.yml`.
